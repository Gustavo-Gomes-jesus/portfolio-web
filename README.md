# portfolio-web
📄 Portfólio Pessoal - Currículo Online
📌 Sobre o Projeto

Este projeto consiste em um portfólio pessoal em formato de currículo online, desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web.

O site apresenta informações profissionais, habilidades, experiências, projetos e formas de contato de maneira organizada, responsiva e moderna.

Importante: Este projeto foi criado exclusivamente para fins de estudo, treinamento e aperfeiçoamento técnico, não representando necessariamente um currículo profissional definitivo.
